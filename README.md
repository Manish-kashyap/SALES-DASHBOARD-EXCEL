📊 Sales Performance Dashboard — Microsoft Excel

🚀 Project Overview

The Sales Performance Dashboard is an interactive Microsoft Excel dashboard designed to analyze and monitor the performance of sales executives across multiple cities.

The dashboard transforms raw sales data into actionable business insights using KPIs, Pivot Tables, Pivot Charts, and interactive slicers. It enables management to quickly identify top performers, underperformers, target achievement, and performance gaps.

---

🎯 Project Objectives

- 📈 Track and evaluate individual sales performance
- 🏆 Identify top-performing sales executives
- ⚠️ Detect underperformers and performance gaps
- 🎯 Compare actual sales against assigned targets
- 🏙️ Analyze performance across different cities
- 💡 Support faster, data-driven business decisions

📌 Key Performance Indicators (KPIs)

💰 1. Total Sales

Measures the total sales generated by each sales executive.

Purpose:
Helps management identify employees contributing the highest revenue.

---

🎯 2. Target Hit %

Measures the percentage of the assigned sales target achieved.

Formula:

"Target Hit % = (Achieved Sales ÷ Target Sales) × 100"

Example:
Anita Dixit — 63.20% Target Achievement

---

📉 3. Away From Target %

Measures the remaining percentage required to reach the assigned target.

Purpose:
Quickly highlights executives who are significantly below their targets.

---

🏙️ 4. City-wise Analysis

The dashboard includes an interactive City Slicer covering:

Chennai • Delhi • Mumbai • Nagpur • Patna • Pune • Ranchi • Surat

Users can select a city and instantly analyze the corresponding sales performance.

📊 Sales Performance Dashboard (Excel)

📌 Project Overview

This project presents an interactive Sales Performance Dashboard built in Microsoft Excel to analyze the performance of sales executives across multiple cities.

The dashboard provides insights into total sales, target achievement, and performance gaps, helping businesses make data-driven decisions and improve overall sales strategy.

---

🎯 Objective

- To track and evaluate sales performance of executives
- To identify top performers and underperformers
- To analyze target achievement vs actual sales
- To support data-driven decision-making

---

🛠 Tools & Technologies Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers (City-wise filters)
- Data Cleaning & Formatting

---

📍 Key KPIs (Key Performance Indicators)

1️⃣ Total Sales

- Displays total sales achieved by each sales executive
- Helps identify top-performing employees

2️⃣ Target Hit %

- Shows percentage of target achieved
- Formula: (Achieved Sales / Target Sales) × 100
- Example: Anita Dixit – 63.20%

3️⃣ Away From Target %

- Indicates how far the executive is from reaching the target
- Helps identify performance gaps

4️⃣ City-wise Filter (Slicer)

- Cities included: Chennai, Delhi, Mumbai, Nagpur, Patna, Pune, Ranchi, Surat
- Enables dynamic filtering of dashboard

---

📊 Dashboard Breakdown

🔹 Dashboard 1: Top 5 Sales Performers

- Displays Top 5 Sales Executives based on total sales
- Helps identify best-performing employees
- KPI Used: Total Sales (Descending Order)

📌 Insight:
Top performers like Rachita Anupam and Jagdish Chandra contribute significantly to overall revenue.

---

🔹 Dashboard 2: Bottom 5 Sales Performers

- Displays Bottom 5 Sales Executives based on total sales
- Helps identify employees needing improvement
- KPI Used: Total Sales (Ascending Order)

📌 Insight:
Executives with lower sales need training, support, or strategy improvement.

---

🔹 Dashboard 3: Target Hit % Analysis

- Shows percentage of target achieved by each executive
- KPI: Target Achievement %

📌 Insight:
Some employees achieve less than 60%, indicating performance gaps.

---

🔹 Dashboard 4: Away From Target %

- Displays the gap between achieved sales and target
- KPI: Target Gap %

📌 Insight:
Helps management take corrective actions quickly.
